# Third-party notices

Lantern's MIT license does not replace dependency licenses. This inventory follows package-lock.json; notices below are copied unchanged from installed packages. Keep upstream notices when redistributing dependencies or built images. Node, PostgreSQL, Caddy, browser binaries, and their base images have separate distributions/licenses; this source release does not bundle those binaries.

The bundled Lantern mark is project artwork. Dashboard screenshots show isolated application fixtures. No conceptual reference mockups or third-party website captures are distributed. Source review found no copied third-party implementation headers; the empirical filename filter identifies itself as an independent implementation. This inspection is not a provenance guarantee for every line.
